# Governance

The A2A Travel Playground uses lightweight, maintainer-led governance.

## Principles

- Decisions are made in public issues and pull requests whenever security or privacy does not
  require confidentiality.
- Compatibility, reproducibility, honest fixture behavior, and contributor clarity take priority
  over framework-specific convenience.
- Maintainers seek rough consensus. When consensus is not possible, maintainers document the
  decision and its tradeoffs.
- No framework, model provider, or hosting platform receives preferential governance rights.

## Maintainers

Maintainers review changes, triage issues, manage releases, and enforce the Code of Conduct.
Consistent contributors may be invited to become maintainers based on technical judgment,
constructive review, reliability, and alignment with the project's principles.

The repository hosting service is the authoritative source for the current maintainer list and
permissions.

## Changes to governance

Material governance changes should be proposed publicly and remain open long enough for active
contributors to comment. Security response and urgent operational changes may be handled privately
first and documented after disclosure is safe.
