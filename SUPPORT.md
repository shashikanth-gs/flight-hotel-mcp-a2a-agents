# Support

Use GitHub issues for reproducible bugs and feature proposals. Use discussions, when enabled, for
setup questions and implementation ideas.

Before requesting help:

1. Read the root README and the relevant document under `docs/`.
2. Run `make check`.
3. Capture the component, command, Python or Docker version, model mode, and complete sanitized
   error output.
4. Remove API keys, authorization headers, prompts containing sensitive information, and other
   secrets.

This community project provides support on a best-effort basis and has no service-level agreement.
Security-sensitive reports must follow [SECURITY.md](SECURITY.md).
